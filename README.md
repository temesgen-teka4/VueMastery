# Vue Mastery - Daily Learning Project

This repository documents my journey learning **Vue.js**, progressing day-by-day from basic concepts to component-driven applications.

## 🚀 Daily Progress

- **Day 1: Vue Foundation**
  - Set up Vite and Vue.
  - Built a basic goal tracker using `ref`, `v-model`, and `v-for`.

- **Day 2: Component Architecture**
  - Split the application into reusable components (`GoalItem.vue`).
  - Implemented **Props** to pass data down and **Emits** to handle events upward.

- **Day 3: Computed Properties**
  - Added computed properties to dynamically track and display the total number of goals.

- **Day 4: Conditional Rendering**
  - Added `v-if` and `v-else` to handle empty states gracefully when no goals remain.

## 🛠️ Tech Stack
